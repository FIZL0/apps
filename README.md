# FIZL0 apps

One sideloading source for every FIZL0 iOS app (AltStore, SideStore, Feather):

    https://fizl0.github.io/apps/source.json

Add it in one tap from <https://fizl0.github.io/apps/>. The source is rebuilt hourly (and when an app releases) from
each app's latest-release `altstore-source.json`; `build.sh` lists the repos.
